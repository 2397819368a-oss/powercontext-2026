【问题 1：结果卡片头部三个元素挤在中间，标签漂在正中】
.result-header 用了 justify-content: space-between 直接放三个子元素（score、类型标签、行号），
空间按间隙均分，于是「赛题 / 代码 / 卡片」这个小标签落在卡片正中间，看着像悬空。
修法：加一层左侧分组，左右各一列。
  HTML:  <div class="result-header">
           <div class="result-meta">
             <span class="result-score">…</span>
             <span class="result-type-tag">…</span>
           </div>
           <span class="result-lines">行 …</span>
         </div>
  CSS:   .result-meta { display: flex; gap: 8px; align-items: center; }
         .result-header 保留 space-between 即可（现在只有两组子元素了）。

【问题 2：摘要直接吐 Markdown 原文】
截图里卡片摘要是这样：
  ## 六、`policy_id` ```python self.policy_id = policy_id # 默认 "http-cross-encoder-v1" ...
  ## 一、接口契约 新增 `powercontext builtin runtime source lifecycle`…
问题有三层：
  a) 行首的 ## 原样出现；
  b) ** 加粗、` 反引号、``` 代码围栏、- 列表符全留着；
  c) 摘要开头重复了卡片上方已经显示过的小节标题（content 第一行就是 H2，heading 字段也是它）。
修法：在 engine.py 里加一个 clean_snippet(text) 清洗函数，snippet 先清洗再截窗口：
  - 去掉行首的 #+ 空格、> 、- / * / + 空格、数字加点（如 "1. "）
  - 去掉 ** __ ` 这些装饰符（注意是去掉符号本身，不是去掉里面的字）
  - ``` 代码围栏整行去掉
  - 把换行和连续空格折叠成单个空格
顺序很关键：先在原始 content 上 find 命中位置，再清洗；清洗后重新 find 一次定位，
找不到就退回清洗后文本的开头截取。别用清洗前的下标去切清洗后的字符串。
  - 如果首行清洗后等于 heading（或清洗后为空），把首行整行丢掉，摘要不要重复标题。
最后仍按 width=120 截，两端补 "..."。
