# Qoder 开发过程录屏脚本

> 交付给评审时用。赛题第 5 项原文：**「关键开发环节的 Qoder 对话截图或录屏，并附 Qoder 账号 UID」**
> —— 截图和录屏二选一即可，本文件走**录屏**这条路。
>
> 目标时长：**3 分半左右**（不超过 5 分钟）。念错、卡顿不用重录，继续往下说就行。

---

## 一、开录屏的三种方法（挑一个能用就行）

### 方法 A：Windows 自带游戏栏（推荐先试）

| 步骤 | 操作 | 备注 |
|---|---|---|
| 1 | `Win + G` 唤出游戏栏 | 第一次会弹「这是游戏吗？」，勾上「是的，这是游戏」并打勾确认 |
| 2 | 点「捕获」面板 → **打开麦克风** | ⚠️ 不打开 mic，录出来没声音，等于白录 |
| 3 | 设置 → 游戏 → 录制 | 把「录制时间上限」调到「4 小时」（默认是「录制时询问」也行） |
| 4 | `Win + Alt + R` | 开始录。屏幕角落出现计时器说明在录了 |
| 5 | 再按一次 `Win + Alt + R` | 停止。视频自动存到 `C:\Users\王海彬\Videos\Captures` |

> 如果某个窗口录不了（游戏栏偶尔会拒 security-sensitive 窗口），先把焦点点到 Qoder 再按快捷键。

### 方法 B：PowerPoint 屏幕录制（当 A 不行时用）

1. 打开任意一个 PowerPoint（没有就新建空白演示文稿）
2. 「插入」→「媒体」→「屏幕录制」→ 勾上**「录制音频」**
3. 点红点开始，录完顶部「停止」
4. 录好的视频在幻灯片上 → **右键 → 媒体另存为** → 存成 `.mp4`

优点：能录桌面和任何应用，不受游戏栏限制。

### 方法 C：手机兜底

手机横屏对着屏幕拍。要求：**看清 Qoder 界面上的字**，最后 UID 那 8 位分组要能辨认。

## 四、照着念（约 3 分 30 秒）

> 括号里的斜体字是动作，不用念。

### 0. 开场（15 秒）
> 「这是 OceanBase 大赛 Qoder 赛道的项目：一个 Obsidian 笔记库的『带出处检索助手』。
> 下面这段是在 Qoder 里从零到一的完整开发过程——这个项目一共迭代了十二轮，我从头往下滚。」

### 1. 滚到第 1 轮，停住（25 秒）
> 「第一轮提需求。我的笔记库有五个目录、二十六篇 Markdown，我要搜一个词的时候，
> 不只要找到文章，还要知道它出自哪个文件的哪个小节、第几行。技术选型是 seekdb 做存储和全文检索。」

### 2. 滚到第 2 轮，停住（25 秒）
> 「第二轮是数据层。要求按 H2 标题切块，把每一块的原始行号记进数据库，中文必须走 ngram 分词。
> 这里能看到它在建表、写导入逻辑。后面实测：默认分词器零命中，ngram 能命中十九条，差距是决定性的。」

### 3. 滚到第 3 轮，停住（25 秒）
> 「第三轮踩坑。它最初把检索写成了 MATCH 两个字段，实际执行报 code 1191，找不到对应的全文索引。
> 我把报错贴回给它，它改成了单列 MATCH。」

### 4. 滚到第 4 轮，停住（35 秒）—— ⭐ 最有说服力的一段
> 「第四轮抓到一个更致命的：凡是带 YAML frontmatter 的文件，入库行号整体偏小十一行。
> 因为解析的时候先把 frontmatter 剥掉了，行号从正文重新数。我抽查了五个块都对不上，
> 让它加了偏移补偿。这个 bug 不修，『带出处』三个字就是假的。」

### 5. 快速滚过第 5、6 轮（20 秒）
> 「第五、六轮做网页界面和命令行，顺带修了末尾行越界——文件以换行结尾的时候，最后一块的行号会多算一行。」

### 6. 滚到第 7 轮，停住（30 秒）
> 「第七轮是验收。二十三个测试全通过，全量二百一十九个块的行号和内容逐字比对，零个不合格。
> 为了确认这个校验不是摆设，我故意把行号加一、把末行多算五行、把标题改错，
> 三种坏数据它全部抓了出来。」

### 7. 滚到第 8、9 轮，停住（25 秒）
> 「第八、九轮修安全问题：搜索关键词带双引号的时候，原来会截断 HTML 属性。
> 我构造了一个注入用例让它改掉。之后又修了卡片排版和摘要里的 Markdown 残留。」

### 8. 滚到第 10、11、12 轮，停住（30 秒）
> 「第十到十二轮做 Qoder Sites 上线。因为 Sites 不支持 Python 运行时，我让它发布成静态镜像版，
> 页面上有免责横幅说明这一点。过程中还发现导出的 JSON 把本机绝对路径公开到了公网，
> 马上做了脱敏；最后一轮修的是条件面板的候选池口径。」

### 9. 切到浏览器，展示成果（30 秒）
> 「这是最终成果，已经发布在公网。搜『重排』，每条结果都带文件名、小节、行号，
> 上面这块是这轮检索的等价条件和命中数。完整实现——seekdb 的 ngram 全文索引加 SQL 过滤——在仓库里，可以本地复现。」

### 10. 切回 Qoder，露 UID（15 秒）—— ⭐ 必须有
> 点头像 → 个人资料页，鼠标把账号 ID 那一行指出来
> 「最后是我的 Qoder 账号 UID，用于核对归属。」

`Win + Alt + R` 停止。
